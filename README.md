#  Simple Text Editor using Python (Tkinter)

This project is a **desktop-based text editor application** built using Python and Tkinter.  
It supports basic file operations such as **New, Open, Save, and Exit**, similar to Notepad.

---

##  Features
- Create a new text file
- Open existing `.txt` files
- Save text to a file
- User-friendly menu interface
- Resizable text editor window

---

##  Technologies Used
- Python
- Tkinter
- File handling
